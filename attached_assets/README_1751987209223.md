# Highrise Discord Bot

A Discord bot that facilitates trading of Highrise metaverse items through a black market system with user verification.

## Features

### User Verification
- Secure account ownership verification using Highrise bio validation
- Two-step process: generate code, add to bio, verify
- Prevents account impersonation and ensures authentic ownership
- 10-minute expiration on verification codes

### Black Market System
- List items for sale with price and category
- Browse marketplace with filtering options
- Purchase items with seller contact facilitation
- Transaction logging and history

### Bot Commands
- `/verify <username>` - Start account verification process
- `/verify_check` - Complete verification after adding code to bio
- `/market [category] [max_price]` - Browse available items
- `/list <item> <price> <category>` - List an item for sale
- `/buy <listing_id>` - Purchase an item (facilitates contact with seller)
- `/help` - Show all commands
- `/status` - Display bot statistics

## Setup

### Prerequisites
- Python 3.11+
- Discord bot token
- Discord server with appropriate permissions

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   pip install discord.py python-dotenv aiosqlite aiohttp pytz
   ```

3. Create environment file:
   ```bash
   cp .env.example .env
   ```

4. Add your Discord bot token to `.env`:
   ```
   DISCORD_BOT_TOKEN=your_discord_bot_token_here
   ```

5. Run the bot:
   ```bash
   python main.py
   ```

## Configuration

The bot uses SQLite for data storage and includes:
- User verification tracking
- Market listings management
- Transaction history
- Action logging

## Trading Process

1. Users verify their Highrise username with `/verify`
2. Sellers list items with `/list <item> <price> <category>`
3. Buyers browse with `/market` and purchase with `/buy <listing_id>`
4. Bot facilitates contact between buyer and seller
5. Users handle the actual item transfer in Highrise

## Database Structure

- **users**: Discord ID, Highrise username, verification data
- **market_listings**: Item details, seller info, pricing
- **transactions**: Purchase records and seller contact info
- **bot_logs**: Action tracking and audit trail

## Security Features

- Input validation and sanitization
- Rate limiting on commands
- SQL injection protection
- User permission checks
- Comprehensive error handling
