# Deployment Configuration Guide

## Required Environment Variables

### Essential (Required for bot to start)
- `DISCORD_BOT_TOKEN`: Your Discord bot token from the Discord Developer Portal

### Optional (For enhanced features)
- `SESSION_SECRET`: Secret key for session management (generates random if not set)

### Note on Highrise API
The Highrise Web API (https://webapi.highrise.game) is completely open and requires no authentication or API keys.

## Deployment Type Recommendation

For Discord bots that need to stay online 24/7, use **Reserved VM** deployment rather than Autoscale.

## Pre-deployment Checklist

1. ✅ Dependencies are managed via Replit's package system (not runtime installation)
2. ✅ Environment variables are set in deployment secrets
3. ✅ Main entry point is `python main.py` (no dependency installation)
4. ✅ Enhanced error handling and logging implemented
5. ✅ Bot token validation added to startup process

## Troubleshooting Common Issues

### Bot fails to start
- Check that `DISCORD_BOT_TOKEN` is properly set in deployment secrets
- Verify the token is valid and the bot has proper permissions
- Check logs for specific error messages

### Connection issues
- Bot includes automatic reconnection logic with exponential backoff
- Monitor logs for connection status and retry attempts

### Database issues
- Bot uses SQLite for local data storage
- Database is automatically initialized on first run
- No external database setup required
